# تنظیمات آزمایشی نمایش بازیکن و شلیک خودکار

**این یک نسخهٔ امن‌شده نیست.** این پوشه فقط یک فایل تنظیمات آزمایشی دارد. فایل‌های `Application.dll` و `ALoader.exe` تغییر نکرده‌اند و خطرهای شناسایی‌شده، از جمله مسیر دریافت و بازکردن فایل از شبکه، همچنان وجود دارند. این فایل تنظیمات هیچ ارتباط شبکه‌ای را مسدود نمی‌کند و هیچ کدی را حذف نمی‌کند. فایل‌های اجرایی را روی سیستم اصلی اجرا نکنید.

در `Settings.ini` این پوشه:

- `visual.espbox.enabled` و `visual.draw.name` روشن مانده‌اند؛ گزینهٔ نمایش تنها دشمن خاموش است.
- `triggerbot.*.enabled` برای همهٔ گروه‌های سلاح روشن شده است؛ `triggerbot.*.autoaim` خاموش است. بنابراین این تنظیم با هدف شلیک خودکار، نه نشانه‌گیری خودکار، تهیه شده است.
- Aimbot، speedhack، knifebot و سایر قابلیت‌های فعال مشخص‌شده خاموش شده‌اند.

فایل از روی تنظیمات اصلی ساخته شده و فایل اصلی دست‌نخورده است. از آنجا که برنامه اجرا و تست نشده، خوانده‌شدن این تنظیمات یا کارکرد و سازگاری آن‌ها تضمین نمی‌شود. برای استفادهٔ ایمن باید برنامه و بارگذار از ابتدا از کد منبع قابل بررسی بازنویسی شوند یا تحلیل و تست امنیتی مستقل بسیار کامل‌تری انجام شود.
